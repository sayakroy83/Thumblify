# Thumblify 🚀

**AI-Powered Thumbnail Generator** — Generate eye-catching thumbnails for your videos with ease.

Live Demo: https://thumblify-client-xi.vercel.app

---

## 🧠 About

Thumblify is a modern web app that helps content creators generate **high-quality and engaging thumbnails** using AI. No design skills required — just describe your idea and let the AI do the work!

✨ Designed for YouTube, Instagram, TikTok, and more.

---

## 🛠️ Features

- ✍️ **Prompt-to-Thumbnail Generation**  
  Create thumbnails based on text prompts.

- 🎨 **AI-Assisted Design**  
  Generates professional visuals automatically.

- ⚡ **Intuitive UI**  
  Simple interface built for creators and marketers.
